# Portal handoff checklist

- Publish the final repository with its open-source license and reproduction steps.
- Put repository URL, model/cost and actual system design in the two-page write-up.
- Export/upload the write-up to Google Docs or Drive and test reviewer link access.
- Upload the <=5-minute narrated video to Google Drive and test reviewer access.
- Optional ZIP: <=150 MB; exclude .env, credentials, caches, node_modules, virtual
  environments and unnecessary media. Include data provenance/setup instructions.
- Paste the write-up URL into WRITE-UP LINK (GOOGLE DOC OR GOOGLE DRIVE).
- Paste the video URL into VIDEO LINK (GOOGLE DRIVE).
- Optionally select the code ZIP, then review the completed form before submission.
