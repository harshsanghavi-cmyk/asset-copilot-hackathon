# Video outline — maximum five minutes

0:00–0:35: Explain the operator problem and one concrete question.
0:35–1:20: Show the final architecture; explain exact calculation, report evidence
and model responsibilities in your own voice.
1:20–2:45: Run a real end-to-end question producing a multi-panel response; inspect
citations, date bounds and one supporting source. Show an actionable explanation.
2:45–3:50: Apply a correction and switch users to show shared propagation; show
that a private conversation reference does not leak to the other user.
3:50–4:30: Explain ten-exchange summary memory and durable facts; show an actual
state or trace without secrets if available.
4:30–5:00: State evaluation outcomes, limitations and next steps.

Choose one coherent real use case. These are planned segments, not a claim that
the product exists. Record with your own narration and keep total duration <=5:00.
