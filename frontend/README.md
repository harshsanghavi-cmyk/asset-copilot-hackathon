# Asset Intelligence workspace

Run `npm ci`, then `npm run dev` in this directory. Open http://localhost:5190. In a second terminal run `npm run runtime` for the self-hosted CopilotKit companion on loopback4190. Python backend is independently owned and defaults to http://127.0.0.1:8000; override `BACKEND_URL` for the runtime and `VITE_BACKEND_URL` for Vite's API proxy. Only Gemma4 31B through Google AI Studio is selected. No provider key belongs in frontend environment variables; there is no alternate-provider option or fallback.

Sample workspace works without a model or backend and is visibly labeled illustrative. Connected workspace loads real profiles and durable conversations from the backend; select it from the header. Titles initially use the first user text deterministically, not an LLM. Manual rename overrides that title. Sample and connected histories are distinct; localStorage caches are profile scoped. Backend APIs remain authoritative for connected history. Local profile selection is not production authentication.

`/admin.html` is a separate local diagnostic entry. `/admin.html#walkthrough?asset_id=WELL-0001` selects the asset walkthrough; the asset selector is general rather than a well-specific mock page. Its explicit allowlisted server proxy reads `../runtime/admin-token` only on demand, forwards the capability server-side, and requires the diagnostic header plus loopback browser origin/referer. It does not authorize chat routes. Do not expose this development server or diagnostic proxy as a public production deployment. The ordinary data explorer retains the backend's explicit capability gate.

The UI validates typed AnswerEnvelope scope, thread, revisions, columns, and ResultSet/EvidenceRef bindings before publication. It renders multiple status/table/line/bar/heatmap/map/diagram blocks without model-generated code. Source text is escaped, raw Markdown HTML/images disabled, and CSV formula prefixes guarded. Geographic maps use Leaflet/OpenStreetMap tiles with attribution; tile access is a documented external network dependency. Optional `VITE_MAP_TILE_URL` must be operator configured, never model supplied.

`npm run test` checks storage isolation, envelope validation, cancellation, backend adapter and bounded runtime capabilities. `npm run typecheck` and `npm run build` validate production compilation. Browser scripts in `tests/` use a separately installed agent-browser CLI and named sessions, and write evidence under `../experiments/04-ui-implementation/`. They deliberately exercise sample mode without provider calls. Live smoke tests must be coordinated with the backend owner and shared model quota.

The companion's in-memory runners are ephemeral: default maximum24 and10-minute idle eviction, configurable within bounds via `RUNNER_MAX` and `RUNNER_IDLE_MS`. Active runs cannot be evicted. Durable conversations are loaded from the Python backend after refresh; the runtime cache is not a database. Production SSO, distributed runners, retention policy, and deployment hardening remain integration work.
